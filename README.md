# Portfolio de Bénédicte

Site web personnel présentant mon parcours en Bachelor Business Data Science et une sélection de projets en analyse de données, programmation et visualisation.

## Fichiers

- `index.html` : contenu du site
- `style.css` : mise en page et styles
- `script.js` : menu mobile et année du pied de page

## Publication avec GitHub Pages

1. Ajouter ces fichiers à la racine du dépôt GitHub du portfolio.
2. Ouvrir **Settings → Pages**.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.
5. Attendre la publication et ouvrir l'adresse fournie par GitHub Pages.

## À personnaliser avant publication

- Remplacer le lien LinkedIn `#` par l'adresse de son profil.
- Remplacer `ton-adresse@email.com` par son adresse e-mail.
- Vérifier que les trois liens GitHub des projets correspondent bien aux dépôts publics.
- Ajuster les textes si les projets ou les compétences évoluent.
